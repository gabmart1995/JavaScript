# Indexedb

Es un componente del navegador que permite almacenar datos sin conexion.
No hay que instalar nada, simplemente validar si el navegador tiene el componente listo.

- Mediana curva de aprendizaje ya que requiere manejo de punteros JS 
- Datos persistentes cuando incluso el cliente apague el equipo
- Permite almacenar archivos e imagenes

## Problemas

- No posee una forma de importar o exportar la data, hay que idear un sistema 
de sincronizacion que gestione la data una vez tener conexion a internet.

- Su almacenamiento es hasta el 60% del disco del equipo. 
Se debe gestionar con el espacio del disco.

### Casos de uso reales
- Sistema de sincronizaciones de internet en caso de no tener conexion remota.
o zonas de dificil acceso.

- Funcionalidades de apps, para guardado temporal de configuraciones de aplicaciones web.
